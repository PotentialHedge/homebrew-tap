# PotentialHedge tap

```sh
brew tap potentialhedge/tap
brew trust --tap potentialhedge/tap   # once; Homebrew 7+ requires trusting third-party taps
```

## tinyMuesli

```sh
brew install --cask potentialhedge/tap/tinymuesli
```

[tinyMuesli](https://github.com/PotentialHedge/tinymuesli): local, private meeting notes for macOS. The cask is updated by `scripts/release.sh` in that repo.

## PubliBike

```sh
brew install --cask potentialhedge/tap/publibike
```

[PubliBike](https://github.com/PotentialHedge/publibike-bar): a tiny menu bar app showing live PubliBike / Velospot bike availability at your favourite and nearest stations.
